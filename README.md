# Rehan Khan — Portfolio

Personal portfolio of **Rehan Khan**, AI Systems Architect | Agentic Orchestration & MCP-driven Ecosystems | Quant-Optimized Intelligence.
B.Tech CSE (AI/ML) at Centurion University of Technology and Management · Co-Founder @ NAVANTA.IO · Bhubaneswar, India.

Built with Next.js, React, Tailwind CSS, GSAP and Lenis. Fully static: no database, no API keys and no environment variables are required.

## Run locally
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Editing content
All personal content (bio, skills, education, projects, links) lives in `src/data/profile.js`.

- Photo: `public/photo/rehan.webp` (also used in `public/og-image.png`).
- Resume: `public/Rehan_Khan_CV.pdf`.
- Optional: set `NEXT_PUBLIC_SITE_URL` to your production domain for canonical/OG URLs (Vercel's production URL is used automatically otherwise).

## Deploy
Import the repo on [Vercel](https://vercel.com/new); the default Next.js settings work as-is.
